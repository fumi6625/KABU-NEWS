# 中立的な時事・経済・株式ニュースソース一覧

上場株式の調査用に、**できるだけ中立的**で、**無料**（会員登録のみは可・有料購読は除外）で読めるニュース源をまとめたものです。
通信社（事実を淡々と配信）と公共放送を中核に据えると、論調の偏りを最小化できます。

> **中立性メモの読み方**
> - 「通信社」＝記者が事実を配信する一次ソースに近く、最も中立的とされる。
> - 「公共放送」＝公的資金で運営。商業的バイアスが小さい。
> - 「中道」＝AllSides / Ad Fontes 等の評価でおおむね中央。
> - RSS URL は Googleスプレッドシートに取り込んで自動更新に使えます（本リポジトリの仕組みで利用）。
> - URL は2026年時点で確認した既知のもの。実際の利用前にブラウザで開いて確認してください。

## 3. 一次情報（最も中立／株式調査の土台）

| ソース | 内容 | 料金 | URL / 取得 |
|---|---|---|---|
| **TDnet 適時開示情報** | 上場企業の公式開示（決算・業績修正・適時開示）。**一次情報** | 無料 | Yanoshin TDnet API: `https://webapi.yanoshin.jp/webapi/tdnet/list/today.rss`（当日分RSS） |
| **EDINET** | 有価証券報告書など法定開示 | 無料 | `https://disclosure.edinet-fsa.go.jp/` |
| **JPX（日本取引所グループ）** | 市場統計・適時開示・規則 | 無料 | `https://www.jpx.co.jp/` |
| **日本銀行 / 内閣府 / 財務省** | 金融政策・GDP・統計 | 無料 | 各官公庁サイト |
| 各社IR・決算ページ | 企業の公式発表 | 無料 | 企業ごと |

> 株式調査では「ニュース（二次情報）」より先に **TDnet / EDINET / 各社IR（一次情報）** を確認すると、中立かつ正確に判断できます。

## おすすめの使い分け（中立性を保つコツ）
1. **事実の確認**：まず通信社（Reuters / AP / 共同 / 時事）と一次情報（TDnet / IR）。
2. **マクロ・市場全体**：NHK・BBC・DW・Bloomberg日本語・CNBC・Trading Economics。
3. **個別株の深掘り**：株探・みんかぶ・東洋経済＋各社IR。
4. **複数ソースで突き合わせ**：1社だけを信じず、通信社＋専門メディア＋一次情報をクロスチェック。
