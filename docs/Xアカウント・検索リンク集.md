# X（旧Twitter）活用ガイド ― 株式の専門ユーザーを無料で追う

X には決算・適時開示・チャート分析を専門に発信するユーザーが多くいます。
ただし **X公式APIは有料化**され、無料で投稿を自動収集するのは現実的ではありません。
ここでは **無料でできる範囲**で、(1) 確実な方法（リンク・リスト）と (2) 補助的な自動化（RSS化）を分けて説明します。

---

## 方法A：検索リンク＆リストで追う（無料・確実・おすすめ）

### A-1. 銘柄ごとの検索リンク
`②個別ウォッチ` シートの「X検索」リンクをクリックすると、その銘柄の最新投稿が開きます。
検索URLの形は次の通り（自分で作る場合の参考）：

```
https://x.com/search?q=$7203 OR トヨタ自動車&f=live
https://x.com/search?q=$AAPL&f=live      ← 米国株は $ティッカー が定番（キャッシュタグ）
```
- `$7203` のように **$＋証券コード**（キャッシュタグ）で検索すると投資家の投稿に絞れます。
- `&f=live` で「最新」順。日本株はコードだけだと別話題が混ざるので **OR 会社名** を足すと精度が上がります。

### A-2. リストを作って“その人たちだけ”を読む（最重要）
気になる専門ユーザーをまとめた**リスト**を作ると、フォローせずにその人たちの投稿だけを一覧できます。
1. Xにログイン →（無料登録でOK）→ 左メニュー「リスト」→「新しいリスト」を作成（例：「決算ウォッチ」）。
2. 信頼できる発信者を追加（下の「探し方」参照）。
3. 作ったリストのURLをブックマークすれば、いつでもその専門家集団のタイムラインだけを読めます。

### A-3. 信頼できる発信者の探し方（中立性のために）
- **一次情報を引用している人**（TDnet・決算短信・有報のリンクを貼る人）を優先。
- **ポジショントーク（自分の保有を煽る投稿）が多い人**は割引いて見る。
- 検索例：
  - `決算 速報 lang:ja -is:retweet min_faves:50`（決算速報をよく出す人を発見）
  - `適時開示 lang:ja -is:retweet`
  - 企業の公式アカウント（IR）も一次情報として有用。
- 必ず**複数人 ＋ 一次情報（TDnet/IR）でクロスチェック**。X単独を売買根拠にしない。

## 方法B：X投稿をスプレッドシートに自動取り込み（無料だが不安定・補助）

> ⚠️ 注意：以下は無料で試せますが、X側の制限で**止まることがあります**。あくまで補助。確実性が要るなら方法A。

### B-1. RSS.app の無料枠を使う
1. [https://rss.app](https://rss.app) に無料登録。
2. 「Twitter / X」用のフィード作成で、追いたい**検索キーワード**や**アカウント/リスト**を指定。
3. 発行された RSS の URL をコピー。
4. スプレッドシートの好きなセルに：
   ```
   =IMPORTFEED("ここにRSS.appのURL","items",TRUE,15)
   ```
   - 無料枠はフィード数・更新頻度に上限あり。

### B-2. RSSHub（公開インスタンス）を使う
- RSSHub は X の検索/ユーザーをRSS化できるOSS。公開インスタンス（例：`rsshub.app`）のURL形式で取得し、同様に `IMPORTFEED` で取り込みます。
- 公開インスタンスは**混雑・停止しやすい**ため、安定運用には自前ホスティングが必要（＝手間）。無料で“とりあえず試す”用途向け。

### B-3. Nitter は基本的に使えない
- かつて定番だった Nitter は X のAPI制限でほぼ停止。`xcancel.com` など一部が残るのみで、**安定しません**。推奨しません。

---

## まとめ（おすすめの落としどころ）
| やりたいこと | 推奨 |
|---|---|
| 確実に専門家を追う | **方法A-2（リスト）** ＋ ②シートの検索リンク |
| 銘柄の“今の空気感”を見る | **②シートのX検索リンク**をクリック |
| どうしてもシート内に集約したい | 方法B-1（RSS.app無料枠）を補助的に |

無料の範囲では「**自動収集に頼り切らず、リンク＋リストで効率的に見に行く**」のが、結局いちばん速くて壊れません。
