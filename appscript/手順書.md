# セットアップ手順書（ターミナル不要・Mac/ブラウザだけ）

所要時間：約10分。プログラミングの知識は不要です。コピー＆ペーストと数回のクリックだけで完成します。

---

## 全体像
- **Stage 1（①注目ランキング）**：監視リストの銘柄を、値動き・出来高・ニュース件数・適時開示を合成した「注目スコア」で自動ランキング。
- **Stage 1.5（③発掘候補）**：**予算（初期5万円）で買える小型・成長・IPO銘柄**だけを、IPOの新しさ・話題性・出来高急増・成長メモで採点して発掘。大手は予算で除外されます。
- **Stage 2（②個別ウォッチ）**：気になった1社を選ぶと、株価・チャート・ニュース・開示・X検索が集中表示。
- データは **1時間ごとに自動更新**（手動更新もボタン1つ）。すべて無料で動きます。

---

## ステップ1：スプレッドシートを新規作成
1. Macのブラウザ（Safari / Chrome）で [https://sheets.new](https://sheets.new) を開く（Googleアカウントが必要・無料）。
2. 左上のファイル名を「**株ウォッチ**」など分かりやすい名前に変更。

## ステップ2：スクリプトを貼り付ける
1. 上部メニューの **「拡張機能」→「Apps Script」** をクリック。
2. 開いたエディタの中身（`function myFunction() {}` など）を**全部消す**。
3. このリポジトリの **`appscript/Code.gs`** の中身を**全部コピーして貼り付け**。
4. 上部の **💾（保存）** をクリック。

## ステップ3：初期セットアップを実行
1. Apps Scriptエディタ上部の関数選択プルダウンで **`setup`** を選び、**「実行」**。
2. 初回は権限確認が出ます → **「権限を確認」→ 自分のGoogleアカウントを選択 →**
   「このアプリは確認されていません」と出たら **「詳細」→「（プロジェクト名）に移動」→「許可」**。
   （※これは自分で作ったスクリプトなので安全です。Googleの仕様で毎回出ます）
3. 実行が終わると、スプレッドシートに `Watchlist` `①注目ランキング` `③発掘候補（少額×成長）` `🔎 新銘柄サジェスト` `📰 M&A・再編ニュース` `②個別ウォッチ` `Sources` の7シートができます。

## ステップ4：監視銘柄を貼り付ける
1. スプレッドシートの **「Watchlist」** シートを開く。
2. 貼り付ける銘柄リストは2種類。**両方つなげて貼ってOK**です（A2セルから順に）。
   - **`data/watchlist_seed.csv`** … 大手・主力（日本株＋米国株）。①注目ランキング向け。
   - **`data/growth_smallcap_seed.csv`** … 日本のグロース・小型・成長株。③発掘候補向け。
3. CSVをテキストで開き、**2行目以降（見出しの下）をコピー** → Watchlist の **A2セル**を選んで貼り付け（**編集 → 特殊貼り付け → 「CSVとして貼り付け」** が崩れにくい）。
   - 2つ目のCSVは1つ目の続きの行（空いている次の行のA列）に貼ります。
   - **列の意味**：A=コード, B=名称, C=市場（`東証グロース` など。「グロース」を含むと小型扱い）, D=Symbol（日本株`TYO:7203`／米国株`NASDAQ:AAPL`）, E=ニュース検索語, F=X検索URL, **G=上場日（任意・IPO判定用）**, **H=かぶミニ可（1株で買えるなら `○`）**。G列以降は空欄でも動きます。
   - 銘柄を増やすときはこの表に行を足すだけ。発掘の精度を上げたいときは、後述の **U列「GrowthMemo」に 1〜5 の成長評価**を手入力できます（5＝高成長）。

## ステップ5：更新する
1. スプレッドシートを再読み込みすると、上部に **「📈 株ウォッチ」メニュー**が出ます。
2. **「📈 株ウォッチ → ① 今すぐ全体を更新」** をクリック。数十秒で①注目ランキングが埋まります。
3. **「⏰ 自動更新(1時間ごと)をON」** を一度押すと、以降は放っておいても1時間ごとに更新されます。

## 使い方
- **Stage 1**：`①注目ランキング` でスコア上位の銘柄を眺める。「個別を見る」リンクで Stage 2 へ。
- **Stage 1.5（少額の掘り出し物）**：`③発掘候補（少額×成長）` を見る。**予算5万円で買える**小型・成長・IPO銘柄が発掘スコア順に並びます。
  - 「予算内の買い方」列で **1単元(100株)** で買えるか、**1株(かぶミニ)** なら買えるかが分かります。
  - 「IPO」「出来高急増」「ニュース」列で話題性を確認 →「個別を見る」で Stage 2 へ。
- **Stage 2**：`②個別ウォッチ` の **B3セル**で銘柄コードを選ぶ（プルダウン）と、その会社の情報が集中表示。
  ニュースを更新したいときは「📈 株ウォッチ → ② 個別ウォッチのニュースを更新」。

### 予算を変えたいとき
Apps Scriptエディタで `Code.gs` 冒頭の `CFG.discovery.budgetYen`（初期 `50000`）の数字を書き換えて保存するだけ。1万円なら `10000`、10万円なら `100000`。

### 🔎 新銘柄サジェスト（新顔を半自動で見つける）
**Watchlistに無い注目の新顔を、システムが自動で拾ってくれます。**
1. メニュー **「📈 株ウォッチ → 🔎 新銘柄サジェストを更新」** を実行。
   - **TDnet当日開示**（上方修正・業績予想修正・株式分割・TOB・新規上場 など）と、**ニュース**（ストップ高／上方修正／新規上場）から、まだ監視していない証券コードを `🔎 新銘柄サジェスト` シートに一覧表示します。
2. 気になる行の **「取込」列のチェックボックス**をON。
3. メニュー **「➕ チェックした新銘柄をWatchlistに取り込む」** を実行 → 自動でWatchlistに追加されます（Symbol・X検索URLも自動入力）。
4. 追加した行の **C列「市場」** に、グロース株なら `東証グロース` を入れる（小型判定に使われます）。必要なら上場日・かぶミニ可も。
5. **「① 今すぐ全体を更新」** を実行 → `③発掘候補` に採点されて並びます。

> サジェストは外部取得が多いので自動更新には入れていません。気が向いたときに手動で「更新」してください。誤って拾ったコードは取り込まなければOK。

### 📰 M&A・再編ニュース（買収・子会社化・分社化 ほか）
**上場企業の組織再編ニュースだけを抜き出して一覧化します。**
1. メニュー **「📈 株ウォッチ → 📰 M&A・再編ニュースを更新」** を実行。
2. `📰 M&A・再編ニュース` シートに、**買収／子会社化／分社化／経営統合／TOB／資本提携**などの記事が新しい順に並びます。
   - **種別**列でどの再編タイプかが分かり、**記事**列のリンクをクリックで本文へ。**関連コード**列は記事から証券コードを拾えた場合に表示。
3. 気になる銘柄（関連コードがある行）は **F列「Watchに追加」にチェック →「➕ チェックしたM&A銘柄をWatchlistに取り込む」** でWatchlistへ。
4. いつでも「更新」を押せば最新に入れ替わります（手動更新）。

> 検索する種別・キーワードは `Code.gs` の **`CFG.maNews.categories`** で自由に追加・編集できます（対象日数は `CFG.maNews.days`、初期7日）。

### 少額×成長株を「発掘」する運用（手動でも探す）
サジェストに加え、自分でも候補を足せます。掘り出し物を増やす無料ソース：
- **JPX 新規上場会社情報** [https://www.jpx.co.jp/listing/stocks/new/index.html](https://www.jpx.co.jp/listing/stocks/new/index.html) … 直近IPO（`G列=上場日`に入れるとIPO加点）。
- **会社四季報オンライン**（無料スクリーニング・無料記事）で「増収増益・小型」を確認。
- **IPO情報サイト**（96ut、トレーダーズ・ウェブIPO など）。
- 株探・みんかぶの「グロース市場」「人気テーマ」一覧は**目で見て**面白い銘柄のコードを拾う（自動取得は規約NG）。
- 見つけた銘柄を Watchlist に1行追加：`Symbol=TYO:コード`、`Market=東証グロース`、分かれば `上場日`・`かぶミニ可○`、必要なら `GrowthMemo` に 1〜5 → 更新。

> ⚠️ **「高成長（増収増益）」の数値は無料では自動取得できません。** ③のスコアは「IPOの新しさ＋話題性＋出来高急増＋小型＋あなたの成長メモ」による**近似**です。
> 買う前の最終確認は必ず **会社四季報オンライン（無料部分）／決算短信（TDnet）／各社IR** で増収増益・財務を見てください。

## 知っておくべき制約（正直な注意点）
- **株価は約20分遅れ**（GOOGLEFINANCEの仕様）。デイトレ用ではなく調査用です。
- **日本株は一部の指標（PER等）が取れない**ことがあります（GOOGLEFINANCEの日本株対応の限界）。`—` 表示になっても異常ではありません。
- **「市場全体の急騰銘柄」を自動で全部拾うことはできません**。楽天証券は東証ほぼ全銘柄＋米国株を扱い、数千銘柄を常時自動取得するとシートが重く・エラーになります。
  → そこで本システムは **監視リスト方式**。気になる銘柄をWatchlistに足して育てる設計です。
  → 新しい急騰銘柄を見つけたいときは、楽天証券アプリや株探の「値上がり率/出来高ランキング」を**目で見て**、面白い銘柄のコードをWatchlistに**手で追加**してください（30秒）。これが無料・合法で最も確実です。
- Yahoo!ファイナンス・株探の画面を自動で読み取る（スクレイピング）のは**規約違反**なので行っていません。ニュースは合法な **Google News RSS** と **公式RSS** から取得しています。
- RSSのURLは2026年時点で確認した既知のものです。万一取得できない場合は `Sources` シートのURLをブラウザで開いて確認してください。

## うまく動かないとき
- ①が空のまま → Watchlistに銘柄を貼ったか確認 → 「今すぐ全体を更新」を再実行。
- ③が空のまま → 予算内で買える小型/グロース/IPO銘柄が無い状態。`growth_smallcap_seed.csv` を貼ったか、`H列=かぶミニ○` を入れたか、`CFG.discovery.budgetYen` を上げたかを確認。
- ニュースが出ない → 数分待つ（RSS側の制限）。`refreshDetailNews` を実行。
- 価格が `#N/A` → そのSymbolの綴り（`TYO:` / `NASDAQ:`）を確認。
- `growth_smallcap_seed.csv` の銘柄コード・上場日は**目安**です。価格やコードが合わないときは最新情報で修正してください。
