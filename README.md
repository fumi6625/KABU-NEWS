# KABU-NEWS ― 注目上場企業ウォッチ＆個別深掘り 2段階システム

上場株式（楽天証券で買える銘柄）の調査用ツール一式です。
**Mac・ブラウザだけで完結／ターミナル不要／無料**（会員登録のみは可・有料購読は不要）で動きます。

## 何ができる？
- **Stage 1：注目ランキング** … 監視銘柄を「値動き・出来高・ニュース件数・適時開示」を合成した**注目スコア**で自動ランキング。今どの企業が話題かを一覧でチェック。
- **Stage 1.5：発掘候補（少額×成長）** … **予算（初期5万円）で買える小型・成長・IPO銘柄**だけを、IPOの新しさ・話題性・出来高急増・成長メモで採点して発掘。大手は予算で除外。「1単元 / 1株(かぶミニ)」どちらで買えるかも表示。
- **🔎 新銘柄サジェスト** … Watchlistにまだ無い新顔を、TDnet当日開示（上方修正・新規上場など）とニュース（ストップ高など）から自動で拾って提案。チェック→ワンクリックでWatchlistに取り込み。
- **📰 M&A・再編ニュース** … 上場企業の**買収・子会社化・分社化・経営統合・TOB・資本提携**ニュースを種別タグ付きで抽出・一覧化。ボタンで更新でき、関連コードが取れた銘柄はWatchlistに取り込み可能。
- **楽天証券リンク／買えるか判定** … 各銘柄に「楽天で買える?（国内現物=○／米国=要確認）」と**楽天証券の銘柄ページへの直リンク**を自動付与（①③②シート＋Watchlist）。
- **Stage 2：個別ウォッチ** … 気になった1社を選ぶと、株価・チャート・ニュース・公式開示・X検索が**集中表示**。

データは Googleスプレッドシート上で **1時間ごとに自動更新**されます。

## 設計の前提（正直な制約）
- 株価は約20分遅延（GOOGLEFINANCE）。調査用であり売買執行用ではありません。
- 楽天証券は数千銘柄を扱うため**全件自動追跡はしません**。流動性の高い銘柄をシードで用意し、気になる銘柄を**監視リストに足して育てる**方式です。
- **「増収増益（成長率）」は無料・無スクレイピングでは自動取得できません**。Stage 1.5 の発掘スコアは「IPOの新しさ＋話題性＋出来高急増＋小型＋手入力の成長メモ」による**近似**です。買う前の最終確認は会社四季報オンライン（無料部分）・決算短信(TDnet)・各社IRで行ってください。
- Yahoo!ファイナンス・株探の画面スクレイピングは規約違反のため不使用。ニュースは合法な **Google News RSS** と各社**公式RSS**から取得。
- Xは公式APIが有料のため、**無料の範囲（リンク・リスト・RSS化）**で対応します。

詳しくは [`appscript/手順書.md`](appscript/手順書.md) の「知っておくべき制約」を参照してください。
